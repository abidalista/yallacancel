# yallacancel

Subscription tracker built for the Saudi & Arabic market.

Live: https://yallacancel.com

## Env (never commit secrets)

See `.env.example`. Production scan needs `ANTHROPIC_API_KEY` as a **Cloudflare Pages** secret. PostHog needs `NEXT_PUBLIC_POSTHOG_KEY` as a **GitHub Actions** secret (inlined at `npm run build`).
